Straight answers

What is Commit Canvas, exactly?

What is Commit Canvas?

Commit Canvas is an open-source tool that turns a git repository into a cinematic, interactive story — chapters, a time machine, a developer fingerprint and share cards — generated from real commit data. The output is a single self-contained HTML file.

Who is it for?

Developers who want to see — and show — how a project actually evolved: maintainers, portfolio builders, teams writing retrospectives, and anyone who has ever wondered what their commit history says about how they work.

How does it work?

The CLI reads your local .git folder in a single pass (commits, merges, tags, authors, per-file line changes) and a deterministic engine derives the story — no AI, no guessing. The web version does the same analysis in your browser through the GitHub API for public repositories.

Does it require an account?

No. There is no sign-up, no login, and no API key. The CLI works fully offline.

Does Commit Canvas store my repository data?

No. There is no backend and no database. The CLI writes one HTML file to your disk. The web version runs entirely in your browser — the only network calls are to GitHub's public API while analyzing a public repo. Generated story files contain commit metadata (authors, dates, messages) — what you choose to share is up to you.

Can it analyze private repositories?

Yes — with the local CLI, which reads the repository on your machine and never sends anything anywhere. The browser version only works with public GitHub repositories.

What can I export?

PNG share cards (X/LinkedIn, square, 9:16 story, README banner), an animated GIF of the time machine, a WebM video, an SVG timeline, a README markdown block, and the full self-contained story.html.

Is it open source?

Yes — MIT licensed. The whole product is on GitHub.

Who created Commit Canvas?

Muhammad Ahmad — a developer building tools at the intersection of developer experience, data storytelling and open source.
