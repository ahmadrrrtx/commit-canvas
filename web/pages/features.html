Features

Statistics tell you what.

Every section of a Commit Canvas story answers a question — and every answer comes from real git data.

S

The story engine

Question it answers: what kind of project is this? Chapters — The Beginning, The Sprint, The Silence, The Grind, The Launch, The Evolution — derived from velocity, gaps and releases. "The project went quiet for 43 days" corresponds to 43 actual days between commits.

deterministic · grounded in timestamps
T

Repository time machine

Question it answers: how did this become what it is? Scrub or autoplay the project's life — commits, contributors, merges, file counts, lines of code and language mix updating month by month, with milestone ticks and cinematic event cards at the moments that mattered.

the flagship
F

Developer fingerprint

Question it answers: how does the dominant author actually work? Favorite hours, weekend share, streaks, burst ratio and message style become one honest archetype — The Night Builder, The Sprinter, The Shipper. Git behavior, explicitly not psychology.

behavior · not a personality test
R

The rhythm

Question it answers: when did the work happen? A weekday × hour punch card, a calendar covering the project's entire life (not just the last 52 weeks), streaks, and night/weekend shares.

full lifetime · accessible summaries
R

Roast my git

Question it answers: what would a kind but honest reviewer say? Vague commit names, monster commits, disappearances, 2–5am activity — every burn ships with its evidence attached.

affectionately brutal
E

Export studio

Question it answers: how do I show this to anyone? PNG cards sized for X/LinkedIn, square and 9:16; an animated GIF of the timeline; WebM video; SVG timelines; a README markdown block; and the entire story as one self-contained HTML file. All generated locally.

Under the hood

Engineering choices you can check.

Single-pass analyzer

One git log subprocess for the whole history — roughly two seconds for a 30,000-commit repository, merge commits kept, no O(N) subprocess spawns.

Zero dependencies

Python 3.8+ standard library and git. That's the entire runtime. The claim is testable: the launcher has no package to install.

Privacy by architecture

The CLI never makes a network request. The output file never makes a network request. There is no backend, no database, and no telemetry — nothing to breach.
